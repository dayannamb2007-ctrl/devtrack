# 🚀 DevTrack

### Tus metas. Tus hábitos. Tu progreso.

DevTrack es una aplicación web de productividad personal diseñada para ayudar a las personas a organizar sus tareas diarias, construir hábitos positivos, establecer objetivos y visualizar su progreso.

## 📌 Sobre el proyecto

DevTrack nace como un reto personal de programación con el propósito de construir una herramienta útil, intuitiva y visualmente atractiva para mejorar la productividad.

El proyecto busca implementar funcionalidades que permitan gestionar actividades diarias, realizar seguimiento de objetivos y mantener un registro de los hábitos personales.

Además, su desarrollo servirá como espacio de aprendizaje y práctica de tecnologías de desarrollo web y buenas prácticas de programación.

## ✨ Funcionalidades principales

### 📋 Gestión de tareas
- Crear nuevas tareas.
- Editar y eliminar tareas.
- Marcar tareas como completadas.
- Organizar tareas por categorías.

### 🎯 Seguimiento de objetivos
- Crear objetivos personales.
- Establecer fechas límite.
- Consultar el progreso de cada objetivo.

### 🔥 Seguimiento de hábitos
- Crear hábitos diarios.
- Registrar actividades realizadas.
- Consultar la constancia y evolución.

### 📊 Panel de productividad
- Visualizar el resumen diario.
- Consultar tareas completadas.
- Visualizar estadísticas de progreso.
